## Cloud Computing Concepts Reflection 
Cloud computing is something I use almost every day, even if I don't always realize it. Some of the cloud services I use the most are Google Drive, Messenger, and Canva. These apps make school and everyday tasks much easier. I use Google Drive to save and organize my files, Messenger to communicate with classmates and friends, and Canva to create presentations and school projects. Since everything is stored online, I can access my work from different devices whenever I have an internet connection.
All three of these applications are examples of Software as a Service (SaaS) because I use the software through the internet without having to install or manage the systems that run it. They are also examples of the Public Cloud deployment model because they are available to anyone who creates an account. Google manages Google Drive, Meta manages Messenger, and Canva manages its platform, so users only use the services instead of worrying about the technical side.
Version control is also an important part of cloud computing. When people work on cloud projects, changes happen often, and it's easy to lose track of what was updated or who made the changes. Version control keeps a record of every update, making it easier to go back to an earlier version if something goes wrong. Without this, it would be difficult to identify who made changes, when those changes happened, and how to recover from mistakes.
GitHub makes teamwork much easier because every member can work on different parts of a project at the same time. Developers can create branches, review code through pull requests, and merge changes only after they have been checked. This reduces conflicts, improves communication, and helps maintain project quality.
GitHub keeps a complete history of every change. If a bug or configuration error appears, developers can quickly compare previous versions and restore a working copy. This saves time and prevents unnecessary delays during development. As I continue learning about cloud computing, I believe knowing how to use Git and GitHub will be an important skill for school projects and my future career in IT.
